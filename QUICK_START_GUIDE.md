# 🚀 Guide de Démarrage Rapide - MMORPG 3D

## 🎮 Comment Commencer à Jouer

### Méthode 1 : Démarrage Rapide (Recommandé pour tester)
1. Ouvrez le jeu à **http://localhost:5174/**
2. Cliquez sur le bouton **"🚀 Démarrage Rapide (Test)"** en haut à droite
3. Sélectionnez une classe de personnage
4. Vous êtes dans le jeu !

### Méthode 2 : Inscription Complète
1. Créez un compte sur l'écran de connexion
2. Sélectionnez votre classe
3. Commencez l'aventure

---

## ⚔️ Comment Lancer votre Premier Combat

### 🎯 Option 1 : Combat Automatique
1. **Déplacez-vous** avec ZQSD ou les flèches directionnelles
2. **Approchez-vous** d'un monstre (cylindre coloré)
3. Le combat démarre **automatiquement** quand vous êtes à moins de **5 cases**
4. Les sorts apparaissent en bas de l'écran !

### 🎯 Option 2 : Combat Manuel
1. Regardez en **haut à gauche** de l'écran
2. Une carte vous indique les monstres à proximité
3. Cliquez sur le bouton **"⚔️ Commencer le Combat Maintenant"**
4. Le combat démarre instantanément !

## 🎨 Interface de Combat Expliquée

### 📊 HUD en Haut (Centre)
- **Tour actuel** : Numéro du tour
- **Tour de** : Nom du personnage qui joue
- **Badge "VOUS"** : S'affiche quand c'est votre tour (fond vert)
- **Stats du joueur** : HP, Mana, PA (Points d'Action), PM (Points de Mouvement)

### ⚔️ Barre de Sorts (Bas)
**Visible uniquement en combat**

#### Quand c'est VOTRE TOUR (bordure verte) :
- ✅ Sorts **actifs** et cliquables
- ✨ Sorts **colorés** selon leur élément
- 💰 Coût en PA affiché en haut à droite
- 🔢 Numéros 1-10 pour les raccourcis (à venir)

#### Quand ce N'EST PAS votre tour :
- ⏳ Message "En attente de..."
- 🔒 Sorts **grisés** et non cliquables
- ⏭️ Bouton "Terminer le Tour" désactivé

### 🎯 Fonctionnement des Sorts

1. **Sélectionner un sort**
   - Cliquez sur une icône de sort
   - Le sort s'illumine avec un ring violet
   - Un curseur apparaît au centre de l'écran

2. **Voir les détails**
   - Survolez un sort pour voir :
     - Nom et description
     - Dégâts min-max
     - Portée min-max
     - Coût en PA
     - Chance de critique
     - Type élémentaire

3. **Cibler un monstre**
   - Un **anneau jaune** apparaît sous les monstres ciblables
   - Survolez un monstre → **anneau vert** + icône 🎯
   - Cliquez pour lancer l'attaque !

4. **Messages d'erreur**
   Si vous ne pouvez pas attaquer, un message apparaît :
   - ⚠️ "Pas assez de PA"
   - ⚠️ "Hors de portée"
   - ⚠️ "Ce n'est pas votre tour"
   - ⚠️ "Cette cible est déjà morte"

### 📜 Journal de Combat (Droite)
- **Défile automatiquement** avec les nouvelles actions
- **Couleurs selon l'événement** :
  - 🎯 Jaune : Coup critique
  - ⚔️ Rouge : Dégâts normaux
  - 💀 Violet : Mort d'un ennemi
  - 🔄 Bleu : Changement de tour
  - ℹ️ Gris : Information

## 🎮 Contrôles du Jeu

### 🚶 Déplacement (Hors Combat)
- **ZQSD** ou **Flèches** : Se déplacer
- **Shift** : Courir (2x plus rapide)
- **Clic droit + Souris** : Tourner la caméra
- **Molette** : Zoom (3 à 20 unités)
- **R** : Ranger/Sortir l'arme

### ⚔️ En Combat
- **Clic gauche sur sort** : Sélectionner
- **Clic gauche sur monstre** : Attaquer
- **Bouton "Terminer le Tour"** : Passer son tour

## 🎯 Stratégie de Combat

### 💡 Conseils pour Débutants

1. **Vérifiez vos PA**
   - Chaque sort coûte des PA
   - Vous avez généralement 10 PA par tour
   - Planifiez vos sorts avant d'agir

2. **Respectez la portée**
   - Chaque sort a une portée min-max
   - Distance affichée au survol du monstre
   - Déplacez-vous si nécessaire (hors combat)

3. **Ciblez intelligemment**
   - Les **boss** (nom "Chef XXX") ont +30% de stats
   - Ils ont un anneau rouge au-dessus d'eux
   - Éliminez d'abord les sous-fifres !

4. **Gérez vos ressources**
   - HP : Points de vie
   - Mana : Pour les sorts magiques (à venir)
   - PA : Points d'action (sorts)
   - PM : Points de mouvement (à venir)

### 🎲 Système de Critique
- Chaque sort a une **chance de critique**
- Coup critique = **x1.5 dégâts**
- Message spécial dans le journal (💥)
- Fond jaune dans les logs

## 🐛 Problèmes Courants

### ❌ "Je ne vois pas les sorts"
**Solution :**
- Assurez-vous d'être **en combat**
- Cliquez sur "⚔️ Commencer le Combat" en haut à gauche
- OU approchez-vous d'un monstre (< 5 cases)

### ❌ "Les sorts sont grisés"
**Raison :** Ce n'est pas votre tour
**Solution :** Attendez que le badge "VOUS" apparaisse et que la bordure devienne verte

### ❌ "L'attaque ne marche pas"
**Vérifiez :**
- ✅ C'est votre tour ?
- ✅ Vous avez assez de PA ?
- ✅ Le monstre est à portée ?
- ✅ Le monstre est vivant ?

### ❌ "Le combat ne démarre pas"
**Solutions :**
1. Approchez-vous plus près des monstres
2. Cliquez sur le bouton "Commencer le Combat"
3. Vérifiez qu'il y a des monstres sur la carte
